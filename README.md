# Myntra Functional Clone

A Myntra homepage clone with a working shopping bag, built with HTML, CSS and JavaScript.
Learning project, not affiliated with Myntra.

## Features
- Homepage with product listings
- Add items to the bag
- Bag page with price summary

## Tech used
HTML, CSS, JavaScript
